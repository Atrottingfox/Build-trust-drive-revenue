## How to use this

**Naming**

- Duplicate this page and rename it `[OPERATOR] - call [N] with Sean`. For board calls use `Content Board Call - [DATE]`.
- Swap every [OPERATOR] and [CLIENT] placeholder before you start writing.
- If someone other than Sean runs the call, rename the Sean's Action Steps section to match.

**Structure, stays fixed**

- Context > What We Covered > Worth Noting > Where to Improve > Next Call > Action Steps.
- `What We Covered` is prose under bold subheads. Not bullets. The reasoning is the value.
- `Worth Noting` and `Where to Improve` are bullets.
- Action steps are always checkboxes, Sean's first, then the operator, then the client if they were in the room.

**Writing it**

- Write for someone reading it cold in three months. Include the numbers, the settings, the names.
- Carry unticked action steps forward from the previous call rather than losing them.
- Toggle extra material (hook lists, scripts, references) under the action step it belongs to.
- Correct transcription errors as you go: names, tool names, client names. Note anything you couldn't confidently resolve.

**Two call types**

- **Weekly.** Operator and Sean. Coaching and direction. Operator has the most action steps.
- **Board call.** Client in the room, monthly. The operator presents the data and the thesis. Add the client's action steps section.
