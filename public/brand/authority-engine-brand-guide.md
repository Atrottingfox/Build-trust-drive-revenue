# The Authority Engine. Brand Assets

Source: authorityengine.com.au / theauthorityengine.live

## Logo

| File | Use |
|---|---|
| `logo/authority-engine-logo.svg` | Master vector. Scales to any size. Use this wherever SVG is supported. |
| `logo/authority-engine-logo-1024.png` | Transparent PNG, 1024px. For decks, docs, anywhere SVG will not load. |
| `logo/authority-engine-icon-512.png` | Square app icon, 512px, dark background. Profile pictures, favicons, app tiles. |

The mark is a split "A". Lighter blue on the left, darker blue on the right.
Always place it on a dark background. Do not recolour it, rotate it, or add effects.

## Header image

`authority-engine-header-1200x630.png` is 1200x630, the social share and header card.
Standard Open Graph size, so it works for LinkedIn, X, Facebook and email headers.

## Colours

### Brand blues
| Name | Hex | Use |
|---|---|---|
| Primary blue | `#3B82F6` | Buttons, borders, primary accents |
| Light blue | `#60A5FA` | Accent text, links, highlights (the most used accent) |
| Deep blue | `#2563EB` | Hover states, gradient ends |
| Logo light | `#5B8DF1` | Left half of the mark |
| Logo dark | `#3568D6` | Right half of the mark |

### Neutrals (the base of the whole system)
| Name | Hex | Use |
|---|---|---|
| Base black | `#09090B` | Page background |
| Surface | `#111113` | Cards, panels |
| Elevated | `#18181B` | Raised cards, hover states |
| Border | `#27272A` | Dividers, card borders |
| Muted text | `#71717A` | Body copy, secondary text |
| Off white | `#E4E4E7` | Headings on dark |
| White | `#FFFFFF` | Primary headlines |

The system is dark first. Black base, white type, blue used sparingly as the accent.

## Typography

**Outfit** (Google Fonts) for everything.
https://fonts.google.com/specimen/Outfit

- Headlines: Outfit 800
- Subheads: Outfit 600
- Body: Outfit 400
- Weights loaded on the site: 300, 400, 500, 600, 700, 800, 900

Fallback stack: `'Outfit', -apple-system, BlinkMacSystemFont, sans-serif`
